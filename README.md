# Rainbow Reins

A unicorn light-bending puzzle for [js13kGames 2026](https://js13kgames.com) — theme: **Unicorns and Rainbows**.

Unicorns fire rainbow beams from their eyes. Spin the plates to bounce the light
around the board and hit every cake with exactly the right color. Beams pass
through cakes and mix where they cross (light adds up — red + green = yellow,
all three = rainbow). Clear the board and the unicorns run over and eat
everything. Nom nom.

- 60 levels across 5 chapters, all generated by code — zero level data in the zip
- Every level is built backwards from a known solution, so it's always solvable
- Par is the *proven* minimum move count (exhaustive search), stars to match
- Tiny WebAudio gallop tune, clip-clop percussion included
- Keyboard + mouse + touch

## Build

```
node pack.mjs    # sprites → dist/pix.js  (indexed palette, packed as a string)
node build.mjs   # bundle → minify (esbuild) → pack (roadroller) → rainbow-reins.zip
```

The build fails loudly if the zip goes over 13,312 bytes, and smoke-tests the
level generator (all 60 levels must be unsolved-at-start and solvable) before
packing.

## Layout

```
src/engine.js   beam simulation · reverse level generation · exact-par search
src/game.js     rendering, input, audio, UI (markup lives in JS for the packer)
src/index.html  thin shell
pack.mjs        sprite packer (PNG → indexed string)
build.mjs       build + size gate
assets/         pixel art (drawn in Aseprite)
```
